# Roadmap

Work I plan to do on the Content Factory (estimated 45+ hours).

- [ ] Merge the duplicated scripts in `scripts/` and `nuvem/` into one shared package (6 h)
- [ ] One config file for paths and brand, instead of values spread across scripts (4 h)
- [ ] Automatic retry and clear error messages when an upload or render fails (4 h)

## Quality

- [ ] Linter for captions and slides (length, banned words, hashtags limit) before the reviewer step (3 h)

- [ ] Approval: approve, edit the caption or reject directly from Telegram buttons (4 h)
- [ ] Multi-platform: export the same post to LinkedIn and TikTok formats (5 h)
